## 📌 About Me

I am a software engineer based in **Addis Ababa, Ethiopia**, specializing in full-stack web development and backend security. I focus on constructing robust, scalable web products, understanding low-level system security, and continuously applying engineering best practices.

* 💻 **Full-Stack Engineering:** Building modern web platforms using React, TypeScript, and Node.js.
* 🔒 **Security & Backend:** Designing safe authentication flows, API security (JWT/Spring Boot), and resilient backend services.
* 🌐 **Infrastructure & Cloud:** Deploying containerized microservices and managing Linux servers.
